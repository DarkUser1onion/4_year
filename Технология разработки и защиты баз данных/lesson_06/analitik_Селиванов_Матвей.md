## Письмо 1. Ревью запросов

### Запрос 1. Заказчику нужны резюме с ожиданиями по зарплате от 100 000 ₽ и выше.

```js
db.resumes.find({ salary: { $gte: "100000" } })
```

- Решение: есть ошибка — значение не того типа: строка вместо числа или логического значения — верно
- Комментарий: В $gte передана строка "100000", а поле salary хранится числом. Сравнение числа со строкой не даёт совпадений- поэтому запрос ничего не нашёл. Нужно передать число без кавычек
- Исправленный запрос:

```js
{ salary: { $gte: 100000 } }
```

### Запрос 2. Найти кандидатов с высшим образованием.

```js
db.resumes.find({ education: { level: "Высшее" } })
```

- Решение: есть ошибка — вложенный документ сравнивается целиком — нужна точечная нотация — верно
- Комментарий: education - вложенный документ, и такой фильтр требует полного совпадения всех его полей. У кандидатов в education есть ещё другие поля (вуз, год и т. п.), поэтому точного совпадения нет. Нужна точечная нотация по конкретному полю
- Исправленный запрос:

```js
{ "education.level": "Высшее" }
```

### Запрос 3. Кандидаты, которые знают и SQL, и Python.

```js
db.resumes.find({ skills: { $in: ["SQL", "Python"] } })
```

- Решение: есть ошибка — не тот оператор для массива: $in вместо $all или наоборот — верно
- Комментарий: $in - это хотя бы один из, то есть логическое ИЛИ. Задача требует и SQL, и Python - логическое И, для массивов это $all. С $in в выборку попадают и те, у кого есть только один навык из двух.
- Исправленный запрос:

```js
{ skills: { $all: ["SQL", "Python"] } }
```

### Запрос 4. Кандидаты, которые проработали в Retail Lab не меньше 12 месяцев.

```js
db.resumes.find({ "experience.company": "Retail Lab", "experience.months": { $gte: 12 } })
```

- Решение: есть ошибка — условия нужно объединить через $or, а они записаны через «и» — неверно
- Комментарий: experience - массив документов. Условия на разные поля массива без $elemMatch проверяются независимо и могут выполниться на разных элементах: например, в одной работе "Retail Lab", а 12+ месяцев - в другой. Нужно, чтобы оба условия выполнились в одном элементе массива.
- Исправленный запрос:

```js
{ experience: { $elemMatch: { company: "Retail Lab", months: { $gte: 12 } } } }
```

### Запрос 5. Открытые вакансии в Москве, где верхняя граница зарплаты не меньше 160 000 ₽.

```js
db.vacancies.find({ city: "Москва", is_open: true, "salary.to": { $gte: 160000 } })
```

- Решение: запрос верный — верно
- Комментарий: Все три условия заданы корректно: city и is_open - точные значения верхнего уровня, salary.to - через точечную нотацию, $gte сравнивает число с числом. Запрос возвращает ровно то, что просили.

### Запрос 6. Все резюме на должности, в названии которых есть слово Python.

```js
db.resumes.find({ position: /python/ })
```

- Решение: есть ошибка — регистр букв: шаблон без флага i — верно
- Комментарий: Регулярное выражение без флага i чувствительно к регистру: /python/ не найдёт "Python-разработчик" с заглавной П. Нужен регистронезависимый поиск.
- Исправленный запрос:

```js
{ position: /python/i }
```

### Запрос 7. Резюме с ожиданиями от 70 000 до 100 000 ₽ включительно.

```js
db.resumes.find({ salary: { $gte: 70000 }, salary: { $lte: 100000 } })
```

- Решение: есть ошибка — ключ в фильтре повторяется — первое условие пропадает — верно
- Комментарий: В объекте-фильтре ключ salary повторяется дважды - в JavaScript/BSON второй ключ перезаписывает первый, и условие $gte: 70000 теряется. Оба ограничения должны быть в одном объекте под одним ключом.
- Исправленный запрос:

```js
{ salary: { $gte: 70000, $lte: 100000 } }
```

### Запрос 8. Финальные собеседования в московских компаниях, которые проходили по видеозвонку.

```js
db.interviews.find({ "company.city": "Москва", format: "видеозвонок", stage: "финальное" })
```

- Решение: запрос верный — верно
- Комментарий: Условия заданы корректно: company.city - точечная нотация по вложенному полю, format и stage - точные строковые значения, все три объединены по "И" на верхнем уровне. Запрос возвращает именно финальные собеседования по видеозвонку в московских компаниях.
