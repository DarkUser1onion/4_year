# Live-центр мониторинга (SignalR)

**Цель проекта** - С нуля создать веб-панель, которая в реальном времени отслеживает активность пользователей: подключения, отключения, сообщения, статус онлайн. Всё должно работать без перезагрузки страницы и без периодических опросов сервера — только SignalR.

**Стек**: ASP.NET Core, SignalR, HTML + чистый JavaScript.
