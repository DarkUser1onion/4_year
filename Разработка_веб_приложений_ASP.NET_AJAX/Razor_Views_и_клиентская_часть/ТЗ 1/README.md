# Панель администратора с динамическими дашбордами

**Цель проекта** — Создать страницу админ-дашборда с карточками показателей, боковой панелью со сводкой по трендам и многоуровневым layout. Освоить продвинутые приёмы Razor: выражения и блоки кода, @functions, секции, условную логику, циклы с переносом строк каждые N элементов, partial-представления, ViewComponent, работу с ViewData/ViewBag, вложенные layouts и _ViewStart/_ViewImports. В результате должно получиться приложение с многоуровневой разметкой (_Layout → _AppLayout → страница), карточками показателей, частичными представлениями и переиспользуемым ViewComponent «Сводка по трендам».

**Стек**: ASP.NET Core MVC, Razor Views (.cshtml), встроенный DI-контейнер, in-memory репозиторий (InMemoryDashboardRepository), ViewComponents, partial views, Bootstrap для вёрстки, HTML-комментарии и Razor-комментарии для документирования.
