# AJAX-интерактивность каталога

**Цель проекта** — Добавить в готовый каталог (модели, layout, Bootstrap-оформление) клиентскую динамику на чистом JavaScript (без jQuery): живой поиск без перезагрузки страницы, добавление товаров в корзину через AJAX, обновление счётчика корзины. Освоить Fetch API, async/await, обработку состояний загрузки/ошибки, работу с DOM-событиями, дебаунс, а также серверные эндпоинты, возвращающие HTML-фрагменты и JSON. В результате каталог должен работать плавно и отзывчиво, без полных перезагрузок при поиске и добавлении в корзину.

**Стек**: ASP.NET Core MVC, Razor Views (.cshtml), vanilla JavaScript (DOM, события, Fetch API, Promise / async-await), Bootstrap 5 (для UI и toast-уведомлений), , partial views для AJAX-ответов, JSON-сериализация.
