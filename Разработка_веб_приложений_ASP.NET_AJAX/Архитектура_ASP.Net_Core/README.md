# Приложение-задачник

**Цель проекта** -  С нуля создать веб-приложение-задачник на ASP.NET Core MVC: реализовать собственные middleware (кастомные заголовки, логирование запросов, замер времени обработки, health-check), подключить сервис через DI (Singleton), создать контроллер с маршрутизацией и model binding, добавить HTML-представления (список, детали, создание задачи) и JSON API для работы с задачами через curl. В результате должно получиться работающее приложение с полным циклом: создание задачи, отметка «выполнено», удаление, просмотр деталей и доступ к данным через API.

**Стек**: ASP.NET Core, MVC (контроллеры + Razor Views), встроенный DI-контейнер, middleware-конвейер, Bootstrap для вёрстки, curl / DevTools для проверки API и заголовков.
